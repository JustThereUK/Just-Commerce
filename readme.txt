== Description ==
**Just Commerce** is a clean, modern, and lightning-fast WordPress theme built specifically for WooCommerce stores.

Designed with performance and SEO in mind, it offers a smooth shopping experience on all devices. Whether you're launching a minimalist boutique or scaling a growing online store, Just Commerce gives you a fast foundation for success.

Built for developers, marketers, and store owners alike, this theme is easy to use, block-ready, and fully compatible with popular page builders and plugins.

== Installation ==

**From the WordPress Admin:**
1. Navigate to **Appearance > Themes > Add New**.
2. Search for **"Just Commerce"**.
3. Click **Install**, then **Activate**.

**Manual Installation:**
1. Download the ZIP file from the [Just There Theme Page](https://justthere.co.uk/themes/just-commerce) or [GitHub Repository](https://github.com/JustThereUK/Just-Commerce).
2. Upload the extracted folder to **wp-content/themes/**.
3. Go to **Appearance > Themes** and activate **Just Commerce**.

== Frequently Asked Questions ==

= Is this theme free to use? =
Yes! Just Commerce is 100% free and open-source under the GPL license.

= Is Just Commerce compatible with the block editor? =
Absolutely. It’s built with block-based design in mind and ready for full-site editing.

= Can I use it with Elementor or other page builders? =
Yes! It works great with Elementor, Spectra, Beaver Builder, and more.

= Does it support WooCommerce out of the box? =
Yes, it's purpose-built for WooCommerce. Product, cart, and checkout pages are fully styled and optimised.

= Can I customise the layout without coding? =
Yes! You can adjust the layout using WordPress Customizer or the Site Editor.

= Will it work with multilingual and multi-currency plugins? =
Yes, it's compatible with major multilingual and currency switcher plugins.
